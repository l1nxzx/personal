## Known gaps and oddities

- No admin/user-management UI; only API routes exist (`/api/users`).
- No client-side tests; no CI configuration (`.github/` does not exist).
- `client/src/pages/LaterPage.tsx` is no longer routed (the vault was its last user). Safe to delete if confirmed unused.
- `client/etc/` and `server/etc/` are empty directories.
- Rate limits are per process unless `REDIS_URL` is set.
- Vault passphrase loss is unrecoverable by design.
- Profile: no active time exists from before the feature shipped (none was recorded). No profile picture. Text copied by an explicit action (quote → note, money idea → project) is counted in both places, as both are separate editable texts. A screen that is locked but still "visible" to the browser keeps counting until the device sleeps. Not verified against live Firestore: aggregation `sum()` and the backfill's BulkWriter preconditions run only against fakes in tests.
- Library: no Trash; deletes are final (a non-empty folder asks whether to keep its contents). No bulk download or folder download (zip). Folders can't be starred. Uploads show per-file status but no byte-level progress (`apiFetch` uses `fetch`). Drag-to-move is desktop only; on touch use Move. "Move contents up" handles up to 2,000 files directly in one folder.
